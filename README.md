# 表情

![表情](packages/cortico-world-bubble-emotes/assets/icon.svg)

让桌宠的问候带上笑意，也让安慰多一点温度。37 个 emoji 与语境提示，把开心、思考和陪伴写进气泡。原版 Coopanion 0.2.8 安装启用即可，无需修改主程序。

当前版本 **0.3.1**。查看[安装与功能说明](packages/cortico-world-bubble-emotes/README.md)。

本次更新统一显示名称、重写描述并加入原创 SVG 图标。普通 Unicode emoji 功能范围保持不变；不支持图片表情包、富气泡渲染，不保证严格身体同步或第三方语音过滤。
