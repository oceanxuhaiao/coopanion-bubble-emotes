# 表达记录：身体心情与动作联合分析

日期：2026-10-25；本地试用版本：0.3.5-dev.3。

每条新表达记录在原有文字、emoji 分析的同一次模型请求中，增加身体表情和动作的独立判定，分别显示“基本协调 / 可能冲突 / 无法确认”及原因。记录卡片中的“身体与动作分析”默认折叠，展开后可查看事件中记录的身体表情、动作与分析依据。没有增加一次独立模型调用，但输入和输出变长，可能增加 token 用量。

## 证据与保护

- 身体表情只识别内置 19 种，独立动作只识别已知动作标识；不根据文字或脸部微动画猜测动作。
- 事件中的标识只代表部分提交意图，不证明动画已经显示，也不代表当前身体状态。
- Coopanion 0.2.8 的普通发言事件通常不包含独立动作，部分内联身体标记也不会进入事件。缺少这些信息时显示“无法确认”，不能解释为没有动作或不匹配。
- 主要情绪分析不可靠时，身体判定也降级为无法确认。模型缺少或写错身体分析字段，不会使有效的文字、emoji 分析整体失败。
- 旧记录不补造历史；手动重新分析只能利用当时保存的信息。身体协调开关独立于记录分析，本次没有新增自动动作。
- 不自动开启表达记录、云端分析或重新分析旧记录。
