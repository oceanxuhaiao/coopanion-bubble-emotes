# 0.3.5 · 表达助手 · 情绪与表情

本次重点：让文字、emoji与身体心情的对应关系可见、可改，并把身体建议纳入草稿检查。动作方面采用保守协调：不自动安排跳舞、跑动、睡觉等独立动作，避免打断用户互动；当前不承诺身体动作同步。

扩展更名为“表达助手 · 情绪与表情”，包名、World ID和数据目录保持不变，现有用户可以直接更新。

- 表情库展示“情绪 → emoji → 身体心情”，支持编辑适用/禁用情绪、19种身体心情映射、对应程度及说明。修改供后续搜索和草稿检查使用。
- 完善37个emoji与身体表情的直接/近似映射，支持用户自定义。
- 草稿检查复用同次情绪分析给出身体心情建议，可单独关闭身体协调。保留中性冲突、睡眠、互动和安静保护。
- 表达记录加入身体心情分析；记录没有身体心情时显示“没有”。不包含动作分析。

边界：Coopanion 0.2.8公开接口缺少可靠实时身体状态，当前实际适配仅提供身体心情建议，不自动追加身体标记或安排动作。草稿检查仍依赖主模型主动调用与采纳，不是全局发送拦截器。事件记录不代表动画显示成功，主动使用效果尚未通过真实行为验收。保留experimental/high-cost标签，云端分析可能产生费用。

验证：100项单元+15项集成，共115项；类型检查、构建、官方扩展检查、真实npm包原生Node加载与桌面/窄屏界面检查通过。配置、表情库与表达记录继续保留。
