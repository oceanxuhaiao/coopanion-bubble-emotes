# 0.4.0 · 简化为表情库与草稿自检

桌宠当前聊天模型提交结构化草稿自检，扩展校验情绪、emoji适宜性与映射，返回当次建议。无需另外配置API、密钥、服务商或Ollama模型。这是主模型自检，不是独立模型复核，仍占用正常聊天上下文与工具调用用量。

- 移除表达记录、发言采集、检查历史、采纳追踪、反馈校准和频率提醒。
- 移除使用引导，直接进入表情库；“草稿与身体设置”折叠区提供两个开关。
- 保留37个emoji、30类情绪和可编辑身体映射；内置表情使用原生句首标记与播放器保护，不执行睡觉、跑动、跳舞等独立动作。
- 不保存草稿或检查历史，不读取旧表达记录和凭证文件；历史文件和库编辑保留。

已有draft-settings.json保留原值；没有该文件的旧版升级采用新版默认开关。主程序自己的对话/工具日志由主程序管理，不在本扩展的保存范围内。

73项单元、20项原版集成，以及类型、构建、官方源包/最终包与普通Node安装包检查通过。保留experimental / high-cost标签，实际主模型调用率、判断准确性和动画时序仍待试用验收，不保证每句调用、自检采纳或动画显示。
