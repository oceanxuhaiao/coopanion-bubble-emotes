# 0.3.0原版兼容精简记录

Owner: packages/cortico-world-bubble-emotes/src/world.ts、web/client.ts和package.json。

目标：原版Coopanion 0.2.8安装、启用扩展后即可使用普通Unicode emoji，不要求修改主程序。

保留：37个emoji、30类含义、中文搜索、使用/避免语境、例句、名称和用法编辑、启停、通过原生pet_say.script单独或随文字发送emoji。习惯状态通过已有公开接口只读显示，读取失败不阻塞表情库。

移除：图片导入与发送、图片表情包、图片文字富混排、定制气泡渲染、presentation/emoji/expression额外发送字段、宿主补丁、离线SVG气泡图案和第三方语音适配器。生产包只含14个文件，无生产依赖，没有compat目录、补丁、PNG解析器、SVG渲染模块或语音替换文件。历史开发文件与0.2.x报告保留供追溯，不再作为新版功能入口或验收结果。

保留旧library.json中的图片条目和图片文件，但界面/搜索/prepare/preview/update均不支持图片，不再读出图片内容或发送blobs。默认安慰字符改为💙：只迁移仍保持原默认Unicode名称和描述的🫂条目，保留自定义用法、禁用/审核状态；非默认字符不改。没有操作用户正在使用的素材目录。

17项测试通过（11项库/World单元测试，6项原版链路/面板/包范围测试）；类型、前端构建、源码及压缩包规范检查通过。压缩包可离线隔离安装，仅安装1个包，不运行安装脚本。

原版链路使用独立且未修改的官方v0.2.8 DesktopPetWorld、真实本机socket与原版linked文本渲染函数；分别验证单独emoji和文字+emoji的标准say消息，确认没有自定义发送字段。这证明标准接口链路可用，不是实际桌宠截图、真实模型使用频率或TTS试听的全流程证明。没有把普通发送回执当作shown确认，也没有修改原版源码来让测试通过。原版源码和语音解析器作为外部验证夹具，位于scratch中，不随扩展发布。

明确限制：系统字体可能缺少某些emoji；没有真实身体确认，不保证严格同步；原版轻核语音0.4.11把emoji保留在TTS输入，本扩展不能保证它跳过emoji，且不修改第三方扩展。需要严格TTS跳过时，须使用语音扩展自身支持并已验证的过滤功能。真实模型情绪评论的零漏发硬指标仍待独立场景验证，未冒充已通过。

此前已安装的宿主/语音补丁不会被自动撤回；要回到官方原版，应使用官方更新或匹配原备份，保留数据，不能用旧主程序文件覆盖新版本。0.3.0不再要求那些补丁。
